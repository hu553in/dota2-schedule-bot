# Dota 2 schedule bot

[English](README.md) | [Русский](README.ru.md)

[![CI](https://github.com/hu553in/dota2-schedule-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/hu553in/dota2-schedule-bot/actions/workflows/ci.yml)

Telegram-бот с расписанием матчей Dota 2, текущими матчами, результатами, сезонами турниров и
избранным. Данные о матчах предоставляет PandaScore. Продакшен работает на Cloudflare Workers и D1.

Чтобы воспользоваться опубликованным экземпляром, открой
[@d2_schedule_bot](https://t.me/d2_schedule_bot). Чтобы бот и его данные находились только в твоих
аккаунтах, следуй
[пошаговой инструкции по самостоятельному развёртыванию](#самостоятельное-развёртывание).

## Возможности

- Поиск команд и сезонов турниров Dota 2 через PandaScore
- Просмотр ближайших, текущих и завершённых матчей с пагинацией
- Ссылки на доступные трансляции будущих и текущих матчей с необязательными иконками Telegram
  Premium для самостоятельно развёрнутых ботов
- Объединение всех стадий в полный сезон турнира
- Отображение турнира и точной стадии в матчах команд
- Скрытие матчей, в которых ещё неизвестны оба участника
- Отображение счёта завершённых и текущих матчей цифровыми эмодзи Telegram
- Сохранение команд и полных сезонов турниров в личное избранное
- Интерфейс, даты, команды и инструкции на английском и русском языках
- Локализация дат средствами Telegram или заданное вручную смещение относительно UTC
- Зашифрованное хранение личного токена PandaScore каждого пользователя в D1
- Обработка продакшен-обновлений через защищённый секретом вебхук Telegram

## Требования к пользователю

- Аккаунт Telegram
- Бесплатный аккаунт PandaScore и личный токен доступа

Бесплатный тариф [PandaScore Schedules, Results & Context Data](https://www.pandascore.co/pricing)
сейчас позволяет выполнять 1 000 запросов к REST API в час. Обычный экран бота требует один или два
запроса, поэтому для личного использования этого тарифа достаточно. Актуальные лимиты указаны в
[справке PandaScore по ограничениям запросов](https://developers.pandascore.co/docs/rate-and-connections-limits).

## Руководство пользователя

### Подключение токена PandaScore

1. [Создай аккаунт PandaScore](https://app.pandascore.co/signup).
2. Открой [панель управления PandaScore](https://app.pandascore.co/dashboard/main).
3. Скопируй значение из поля **Your access token**.
4. Открой личный чат с ботом.
5. Перейди в **Настройки** -> **Токен PandaScore** -> **Ввести токен**.
6. Отправь токен ответом на сообщение бота.

Бот сразу пытается удалить сообщение, проверяет токен через PandaScore и сохраняет его только после
успешного выполнения обеих операций. Если Telegram не может удалить сообщение, токен не сохраняется.
Удали сообщение вручную, перевыпусти токен в PandaScore и попробуй снова.

Чтобы позже проверить сохранённый токен, используй кнопку **Проверить** или команду `/status`.
Замена или удаление токена не удаляет избранное.

### Поиск команды

1. Нажми **Найти команду** в главном меню.
2. Ответь на сообщение бота названием длиной не менее двух символов, например `Team Spirit`, `OG`
   или `Liquid`.
3. Выбери команду из списка результатов с постраничной навигацией.
4. Переключайся между вкладками **Сейчас**, **Ближайшие** и **Результаты**.

У каждого матча команды указаны сезон турнира и точная стадия. В карточке матча также отображаются
актуальное запланированное или фактическое время начала, смещение UTC при ручной настройке, формат
матча, например `BO3` или `FT3`, доступный счёт и ссылки на трансляции будущих или текущих матчей.

Если ничего не нашлось, ответь на то же сообщение другим или более коротким названием. Нажимать
отдельную кнопку повторного поиска не нужно.

### Поиск турнира

1. Нажми **Найти турнир** в главном меню.
2. Ответь названием сезона, например `Esports World Cup 2026`, `The International` или `ESL One`.
3. Выбери полный сезон, например `Esports World Cup · 2026`.
4. Просматривай матчи всех стадий через те же вкладки: **Сейчас**, **Ближайшие** и **Результаты**.

PandaScore представляет отдельные стадии как турниры внутри серии. Бот намеренно показывает серию
пользователю как единый сезон турнира. Поэтому в избранном сохраняется полный сезон, а не отдельная
стадия плей-офф, квалификации, группового этапа или Survival. Точная стадия PandaScore остаётся
видна у каждого матча.

### Просмотр матчей

- **Сейчас** открывается по умолчанию и всегда занимает собственную строку клавиатуры.
- **Ближайшие** показывает запланированные матчи в хронологическом порядке.
- **Результаты** показывает только матчи, которые PandaScore пометил как завершённые, начиная с
  самых новых.
- Во всех списках используются одинаковые кнопки перехода назад и вперёд.
- Матч с одним неизвестным участником остаётся видимым с подписью `Участник уточняется`.
- Матч с двумя неизвестными участниками скрывается.
- Счёт текущих и завершённых матчей отображается цифровыми эмодзи; недоступный счёт обозначается как
  `❔`.
- Ничьи, перенесённые матчи и неизвестные статусы отмечаются явно.

Трансляции выводятся ссылками через запятую. Английский и русский языки трансляций обозначаются как
`🇺🇸` и `🇷🇺`; коды остальных языков остаются текстовыми. В стандартном режиме ссылка включает всю
подпись и информацию в скобках, например `Twitch (🇷🇺 основной)`. В самостоятельно развёрнутом боте
название известного провайдера можно заменить кастомным эмодзи; вся информация в скобках при этом
остаётся ссылкой.

### Использование избранного

Открой команду или сезон турнира и нажми **☆ Добавить в избранное**. Сохранённые элементы появляются
в разделе **Избранное**, откуда их матчи открываются одним нажатием. Чтобы удалить элемент, нажми
**★ Удалить из избранного** на том же экране матчей.

Избранное хранится отдельно от токена PandaScore. Оно остаётся доступным после замены или удаления
токена, но для загрузки матчей по-прежнему нужен действующий токен.

### Смена языка

Открой **Настройки** -> **Язык** и выбери **🇺🇸 English** или **🇷🇺 Русский**.

Пока язык не выбран вручную, бот использует язык устройства Telegram, если это русский, и английский
для всех остальных языков. Сохранённый язык применяется ко всем экранам бота, инструкции по
развёртыванию и датам при ручном смещении UTC. В автоматическом режиме Telegram определяет не только
часовой пояс, но и язык даты.

### Настройка часового пояса

Открой **Настройки** -> **Часовой пояс**.

В автоматическом режиме поддерживаемые клиенты Telegram отображают время в часовом поясе устройства.
Telegram не сообщает ботам фактический часовой пояс устройства, поэтому клиенты без локализации
времени могут показывать UTC. В этом случае:

1. Нажми **Указать смещение**.
2. Ответь значением, например `+6`, `-3` или `+5:30`.
3. Вернись к любому списку матчей: сохранённое смещение будет применяться ко всем датам.

Чтобы удалить ручное смещение, отправь `авто` или нажми **Автоматически через Telegram**. Допустимый
диапазон — от `-12:00` до `+14:00`.

### Команды

| Команда       | Описание                                 |
| ------------- | ---------------------------------------- |
| `/start`      | Открыть главное меню                     |
| `/favorites`  | Открыть избранное                        |
| `/timezone`   | Открыть настройку часового пояса         |
| `/settoken`   | Подключить или заменить токен PandaScore |
| `/status`     | Проверить сохранённый токен PandaScore   |
| `/cleartoken` | Удалить сохранённый токен PandaScore     |
| `/help`       | Показать руководство внутри бота         |

Бот предназначен для личных чатов. Команды и кнопки, использованные в группе, направляют
пользователя в личный чат, чтобы токены и личные настройки разных пользователей не смешивались.

## Самостоятельное развёртывание

Эта инструкция проводит от пустого аккаунта Cloudflare до работающего личного бота. Опыт разработки
Telegram-ботов или работы с Cloudflare не нужен. Выполняй команды ниже в терминале по одному блоку.
Если команда открывает браузер, закончи вход там и вернись в терминал.

### 1. Установи необходимые инструменты

Понадобятся:

- [Git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/en/download)
- [Bun](https://bun.sh/docs/installation)
- Бесплатный [аккаунт Cloudflare](https://dash.cloudflare.com/sign-up)
- Аккаунт Telegram

После установки закрой и снова открой терминал. Эти команды должны вывести версии программ, а не
ошибку:

```bash
git --version
node --version
bun --version
```

В Windows используй WSL или Git Bash для команд из этой инструкции.

### 2. Создай Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram и отправь `/newbot`.
2. Выбери отображаемое имя, которое увидят пользователи.
3. Выбери имя пользователя, заканчивающееся на `bot`, например `my_dota_schedule_bot`.
4. Скопируй токен, который пришлёт BotFather. Считай его паролем и нигде не публикуй.

Токен выглядит примерно как `123456789:AA...`. На следующем шаге ты добавишь его в локальный файл
конфигурации.

### 3. Скачай и настрой проект

Скачай репозиторий, перейди в его папку, установи точные версии зависимостей из lock-файла и создай
личную локальную конфигурацию:

```bash
git clone https://github.com/hu553in/dota2-schedule-bot.git
cd dota2-schedule-bot
bun ci
cp .dev.vars.example .dev.vars
```

Открой `.dev.vars` в любом текстовом редакторе и замени только значение `BOT_TOKEN` на токен от
BotFather. Остальные две заглушки пока не меняй:

```env
BOT_TOKEN=123456789:replace-with-the-real-bot-token
PS_MASTER_KEY=replace_with_base64_encoded_32_random_bytes
WEBHOOK_SECRET=replace_with_random_secret
```

Не загружай `.dev.vars` в интернет, не добавляй его в Git и никому не отправляй.

### 4. Проверь бота локально

Запусти локального бота:

```bash
bun dev
```

При первом запуске скрипт безопасно создаст `PS_MASTER_KEY` и `WEBHOOK_SECRET` в `.dev.vars`,
создаст локальную базу D1, применит миграции, настроит команды Telegram и выведет ссылку на бота.
Открой эту ссылку в Telegram и отправь `/start`. Локальные данные хранятся в `.wrangler/`.

Чтобы остановить бота, нажми `Ctrl+C` в терминале.

Локальная разработка использует Telegram long polling, который удаляет существующий вебхук того же
бота. После публикации используй для локальной разработки второго бота от BotFather или снова
выполни `bun deploy`, когда закончишь проверку.

### 5. Создай базу Cloudflare

Авторизуй Wrangler в своём аккаунте Cloudflare:

```bash
bunx wrangler login
```

Создай продакшен-базу D1:

```bash
bunx wrangler d1 create d2-schedule-bot
```

Wrangler выведет UUID `database_id`. Открой `wrangler.jsonc` и замени существующее значение
`database_id` на этот UUID. Нужно изменить только значение между кавычками. При желании также можно
изменить верхнеуровневое поле `name`, под которым Worker отображается в панели Cloudflare.

### 6. Опубликуй бота

Опубликуй Worker и подключи его к Telegram:

```bash
bun deploy
```

Команда загрузит секреты из `.dev.vars`, применит удалённые миграции D1, опубликует Worker, настроит
защищённый вебхук и команды на английском и русском языках, а затем проверит итоговый URL вебхука.
После успешного завершения открой бота в Telegram и отправь `/start`.

Храни безопасную резервную копию `.dev.vars`. Особенно важно не менять `PS_MASTER_KEY` после того,
как пользователи подключили токены PandaScore: новый ключ не сможет расшифровать существующие
токены. Повторно выполнять `bun deploy` с тем же файлом безопасно.

### 7. Установи изображения через BotFather

Готовые изображения находятся в `assets/botfather/`. В BotFather отправь `/mybots`, выбери бота и
открой **Edit Bot**:

- Выбери **Edit Botpic** и загрузи [`botpic.png`](assets/botfather/botpic.png) как изображение
  профиля.
- Выбери **Edit Description Picture** и загрузи
  [`description-picture.png`](assets/botfather/description-picture.png) как изображение рядом с
  описанием бота для новых пользователей.

### 8. Необязательно: включи Premium-иконки провайдеров трансляций

Общедоступный набор [`Dota 2 Stream Providers`](https://t.me/addemoji/Dota2StreamProviders) и его ID
уже настроены. Если у аккаунта, которому принадлежит бот, есть Telegram Premium, измени
`TELEGRAM_PREMIUM` на `"true"` в `wrangler.jsonc`, выполни `bun check` и разверни бота.
Пользователям Premium не нужен. В остальных случаях оставь стандартное значение `"false"` — бот
продолжит выводить полные текстовые ссылки. Обычные эмодзи, назначенные при создании набора,
существуют только как обязательные заглушки Telegram внутри сущностей кастомных эмодзи. Telegram
может показать такую заглушку в системном уведомлении или пересланном сообщении, где кастомный
эмодзи нельзя отобразить; сам бот никогда не использует её как отдельную подпись провайдера.

Чтобы пересобрать иконку или создать независимый набор, следуй короткой инструкции
[`PACK.md`](assets/custom-emoji/dota2-stream-providers/PACK.md). В репозитории остаются только
готовые к загрузке WEBP-файлы, ссылки на источники и команда конвертации. Для другого набора замени
соответствующие публичные значения `customEmojiId` в `src/bot/streams.ts`.

### Автоматическое развёртывание из Git

Ручного развёртывания выше достаточно для работы бота. Чтобы будущие изменения публиковались
автоматически, создай форк этого репозитория в своём аккаунте GitHub и подключи его через Cloudflare
Workers Builds:

1. Открой Worker в Cloudflare -> **Settings** -> **Build** и подключи GitHub-репозиторий.
2. В поле **API token** выбери или создай токен, который может публиковать Workers и имеет
   разрешение **Account** -> **D1** -> **Edit** для нужного аккаунта.
3. Укажи `main` как продакшен-ветку.
4. Укажи `bun check` как команду сборки.
5. Укажи `bun deploy` как команду развёртывания.
6. Отключи сборки непродакшен-веток, если preview-развёртывания не нужны.
7. Добавь `BOT_TOKEN` и `WEBHOOK_SECRET` как секреты сборки со значениями из `.dev.vars`.
8. Добавь `NODE_VERSION` и `BUN_VERSION` как переменные сборки, используя минимальную версию Node.js
   и версию Bun из `package.json`.

Первое ручное развёртывание уже создаёт секреты среды выполнения Worker. Не удаляй `BOT_TOKEN`,
`PS_MASTER_KEY` и `WEBHOOK_SECRET` из раздела **Variables and Secrets**. Секреты сборки существуют
отдельно и доступны только во время выполнения команды развёртывания в Cloudflare.

Справочные материалы по конфигурации Cloudflare:

- [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/)
- [Конфигурация сборки](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/)
- [Разрешения API-токенов](https://developers.cloudflare.com/fundamentals/api/reference/permissions/)
- [Секреты Worker](https://developers.cloudflare.com/workers/configuration/secrets/)
- [Миграции D1](https://developers.cloudflare.com/d1/reference/migrations/)

## Справочник конфигурации

Конфигурация среды выполнения проверяется в `src/config.ts`.

| Имя                | Расположение                | Обязательно | Описание                                                    |
| ------------------ | --------------------------- | ----------- | ----------------------------------------------------------- |
| `BOT_TOKEN`        | Секрет                      | Да          | Токен Telegram-бота                                         |
| `PS_MASTER_KEY`    | Секрет                      | Да          | 32-байтовый мастер-ключ AES-GCM в кодировке base64          |
| `WEBHOOK_SECRET`   | Секрет                      | Да          | Секрет вебхука Telegram: 32–256 URL-безопасных символов     |
| `BOT_NAME`         | Переменная `wrangler.jsonc` | Да          | Отображаемое имя бота без сетевого запроса                  |
| `BOT_USERNAME`     | Переменная `wrangler.jsonc` | Да          | Имя пользователя бота без `@`                               |
| `TELEGRAM_PREMIUM` | Переменная `wrangler.jsonc` | Нет         | Есть ли Premium у владельца бота; по умолчанию `false`      |
| `DB`               | Привязка D1                 | Да          | База D1 для токенов, избранного и пользовательских настроек |

`bun dev` и `bun deploy` синхронизируют `BOT_NAME` и `BOT_USERNAME` с ботом из BotFather.
`WEBHOOK_SECRET` должен иметь одинаковое значение в развёрнутом Worker и в среде, где выполняется
`bun deploy`. `TELEGRAM_PREMIUM` принимает только `"true"` или `"false"`; даже во включённом режиме
для кастомных эмодзи требуются корректные ID провайдеров.

## Данные и безопасность

D1 содержит три прикладные таблицы:

- `user_tokens` хранит один зашифрованный токен PandaScore для каждого пользователя Telegram
- `user_favorites` хранит сохранённые команды и сезоны турниров
- `user_preferences` хранит необязательные язык и ручное смещение UTC

Токены PandaScore шифруются с помощью AES-256-GCM. При каждой записи используется случайный
96-битный IV, а идентификатор пользователя Telegram включается как аутентифицируемые дополнительные
данные. Зашифрованное значение, скопированное для другого идентификатора пользователя, невозможно
успешно расшифровать.

Запросы к вебхуку должны содержать настроенный секретный заголовок Telegram. Взаимодействие с ботом
ограничено личными чатами, сообщения с секретами удаляются до сохранения, а ошибки журналируются без
секретных значений.

Пользователи, которые не хотят доверять опубликованному экземпляру, могут развернуть этот
репозиторий в собственном аккаунте Cloudflare и использовать личную базу D1. Полный исходный код
доступен на [github.com/hu553in/dota2-schedule-bot](https://github.com/hu553in/dota2-schedule-bot).

## Поведение среды выполнения

- Продакшен использует вебхуки Telegram, локальная разработка — long polling
- Запросы PandaScore ограничены тайм-аутами отдельного запроса и всей операции с одной повторной
  попыткой GET, которую выполняет библиотека
- Страницы поиска, матчей и избранного содержат по шесть элементов
- Избранный турнир представляет собой серию PandaScore; отдельные стадии никогда не сохраняются
- Переводы загружаются i18next из статических JSON-ресурсов, а не из базы данных
- Язык и смещение UTC загружаются из D1 при каждом обновлении
- В автоматическом режиме даты используют язык и часовой пояс устройства через Telegram, а в ручном
  — сохранённый язык и смещение UTC
- Предпросмотр ссылок в сообщениях бота отключён
- Названия трансляций и вся информация в скобках являются ссылками; настроенные Premium-иконки
  заменяют только названия известных провайдеров
- Наблюдаемость Cloudflare включена в `wrangler.jsonc`

## Разработка

Запусти полную локальную проверку:

```bash
bun check      # Полная локальная проверка
bun check:fix  # Полная локальная проверка с автоисправлениями
```

Отдельные команды:

```bash
bun lint           # Запустить проверку Ultracite
bun lint:fix       # Применить исправления Ultracite
bun check:types    # Сгенерировать типы Worker и запустить TypeScript
bun run build      # Проверить сборку без развёртывания
bun check:unused   # Запустить Knip
bun check:vulns    # Проверить production-зависимости
bun run test       # Запустить Vitest
bun test:coverage  # Проверить пороги покрытия
```

## Структура проекта

```text
assets/botfather/     Готовые изображения для Telegram-бота
assets/custom-emoji/  Готовые эмодзи провайдеров и короткая инструкция
migrations/           Миграции схемы D1
scripts/              Точки входа локальной разработки и продакшен-развёртывания
src/api/              Клиент PandaScore и схемы ответов
src/bot/              Обработчики grammY, клавиатуры, сообщения и runtime-хелперы
src/locales/          Статические переводы на английский и русский языки
src/storage/          D1-хранилища токенов, избранного и настроек
tests/                Тесты Worker, API, хранилищ, сообщений и обработчиков
wrangler.jsonc        Конфигурация Cloudflare Worker, D1, переменных и наблюдаемости
```
